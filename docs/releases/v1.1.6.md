# v1.1.6 — 盖板纯图标 / 大屏手机误判修正 / 返回键去重 / 握手卡持续隐藏

> 版本：`1.1.6+17`。基于 v1.1.5 真机截图反馈（用户提供了盖板与握手卡
> 的实拍图），修四处体验问题。

## 变更

**1. 启动盖板改为纯图标**

去掉盖板上的转圈指示器——按用户要求只保留应用图标（静默加载）。

**2. 大屏手机不再被误判成平板（阈值 600 → 700dp）**

真机反馈：用户的折叠屏手机（最短边约 606dp）在 v1.1.5 被判成平板，
导致手机上的设置返回/页内返回走了平板路径。阈值提到 700dp：606dp 的
大屏手机回到手机路径（设置返回=设备列表页、对话页返回=对话列表），
800dp 的 Pixel Tablet 仍走平板路径（设置返回=对话/列表同屏页）。

**3. 设置返回后吞掉同一次操作的多余返回键**

真机反馈："我只返回了一次，它返回了两次"——设置返回揭示远控页后，
同一次返回键在部分机型上会被再派发一次，把刚揭示的页面又顶回去。
现在揭示后 900ms 内到达的返回键按同一次操作的多余派发吞掉
（`_settingsRevealedAt` 守卫）。

**4. 握手卡（"已配对，正在加载工作区…"）持续隐藏**

真机截图实锤两个缺陷：① 隐藏器"命中一次即断开"，而配对流程会多次
重建这张卡，重建后的卡没人再隐藏；② 遗留一个 5 秒硬停定时器，让
观察窗时长形同虚设。改为：命中不断开，持续观察直到**工作区真正就绪**
（任务行/输入区出现）或 60 秒上限；冷启动期间与切换会话时的这张卡
一律冷处理，不再弹出。

## 返回层级（现行口径，不变）

| 场景 | 手机 | 平板（≥700dp） |
| --- | --- | --- |
| 设置/诊断/扫码 返回 | 设备列表页 | 对话+列表同屏页 |
| 对话页 返回 | 对话列表 | 设备列表页 |
| 对话列表 返回 | 设备列表页 | —（同屏） |
| 设备列表页 返回 | 退出 | 退出 |

## 验证

- `flutter analyze` 零问题；注入脚本校验器 32/32；back_navigation 16/16
  （isTabletLayout 边界新增 606dp 折叠屏用例）；全套测试以 CI 为准。
- 模拟器实测：冷启动盖板为纯图标；握手卡在配对期被持续隐藏；
  手机（320×640）设置返回停设备列表页；平板（800×1280dp）设置返回
  停同屏页且不再被多余返回键顶回。
