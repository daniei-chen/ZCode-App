## ZCode App v1.1.1

> 本版是 v1.1.0 审计加固内容的**正式发布版本**（v1.1.0 的 tag 打在加固完成前，
> 随后 main 又被来源门禁要求"tag 提交必须等于当前 main HEAD"所拒——按规则不移动
> 已存在的 tag，改为以 1.1.1 发布全部内容）。默认以 **Pre-release** 发布：
> 应用内更新器只认 `/releases/latest`，不会向普通用户推送。

### 包含内容

v1.1.0 计划的全部加固（可靠性 / 通知与交互 / 观测与诊断 / 安全 / 无障碍 / 发布与
供应链），详见 [v1.1.0.md](v1.1.0.md)；本版在此基础上再补两项：

- **出站请求 URL 策略**：应用发起的每个服务端请求都要求 https + host 白名单
  （github.com / api.github.com / 发布资产 CDN），并拒绝 localhost、环回、私有、
  保留与链路本地地址；**重定向逐跳校验**（此前客户端自动跟随重定向可绕过白名单，
  而 GitHub 发布资产正是靠 302 跳到 CDN）。
- **CI 依赖固定 SHA 升级**：`subosito/flutter-action` v2.21.0 → v2.23.0（模拟器作业
  此前在 `Set up job` 阶段报无法解析旧 SHA，升级后已能正常进入模拟器运行阶段）。

### 用户可见修复

- **手机端对话页按返回不回对话列表**：页内返回改为多策略匹配（含纯图标返回键的
  左上角几何启发式）+ 点击后内容签名自证 + 结果回执；平板不再被短路；
- **返回层级补齐**：设置/诊断等推入页面先弹栈回到上一个页面 → 对话页回对话列表 →
  对话列表露出设备页 → 设备页退出应用（手机与平板同一套规则）。

### 已知边界

- 支持范围与限制见 [docs/SUPPORT.md](../SUPPORT.md)（Android 7.0+、仅 arm64-v8a、
  不支持 iOS；CI 实测 API 30/34）。
- v1.1.0 的 tag 保留但未发布；如需清理需调整 tag 规则集（当前规则集禁止删除/移动
  tag，这是审计验收项之一）。
