# WorkBuddy 移动端参考笔记

> 目的：把 WorkBuddy 安卓版的信息架构与设计语言作为 ZCode Control 的 UI 基准。
> 仅记录分析结论，不包含任何从安装包提取的专有资产（图标/字体/二进制均不入库）。

## 包体分析结论

- **框架**：Flutter 应用（与本项目同框架，参考价值直接）
  - `lib/arm64-v8a/libapp.so` 为 Dart AOT；`assets/flutter_assets` 结构标准
- **资源规模**：约 416 个自绘 SVG/PNG 图标资源，说明其走"自绘组件 + 少量平台控件"路线
- **字体**：默认 Material 字体 + 中文系统字体栈（无内嵌商用字体）
- **底部 Tab 结构**（从 Dart 字符串与页面骨架推断）：任务 / 活动 / 自动化 / 技能 / 专家 —— 内容型 Tab + 服务型 Tab 混排，状态胶囊贯穿全部列表

## 借鉴的设计语言

1. **卡片流为主的信息单元**：大圆角（16–20）、hairline 描边、无投影，列表按"今天/昨天/本周"日历分组
2. **状态胶囊**：小圆角 pill（进行中/等输入/完成/失败），颜色即语义，附数字徽标表达"等几件事"
3. **底部导航**：5 Tab 以内，通知 Tab 带未读徽标与警示红点
4. **头部大标题**：26pt 粗体 + 灰色副标题（同步状态/计数），列表顶部不做 AppBar
5. **空态**：彩色浅底圆角容器 + 图标 + 一句引导文案，不放按钮
6. **细节动效**：状态点呼吸/闪烁（有限、语义化），页面转场淡入 + 轻微上滑

## 映射到本项目

| WorkBuddy | ZCode Control | 数据源 |
|---|---|---|
| 任务 Tab 卡片流 | TasksPage 跨设备任务卡 | sessionIndex |
| 状态行（进行中/工具调用） | 原生详情页状态胶囊 | phase 事件 + pendingInteraction |
| 通知中心 | NotificationsPage | eventFeed 事件历史 |
| 技能/专家入口 | 工作台九宫格面板 | 桥接面板快照 |
| 底部 5 Tab | 任务/工作台/通知/设备/设置 | — |

## 明确不抄的部分

- 不复刻其品牌视觉（配色/图标/字体）
- 不复刻其依赖账号体系的云同步（本项目数据全在局域网桥接）
