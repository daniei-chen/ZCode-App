## ZCode App v1.0.6

纯 WebView 架构定格 + 更新链闭环。

### 变更

- 架构定格为"原生外壳 + 内置 WebView"：移除原生 relay 数据面与会话面板，任务与会话统一由官方远程控制页承载
- 更新器加固：回退路径不伪造下载地址、断点续传（Range/206/416 校验）、200MB 上限、SHA256 摘要校验
- WebView 导航白名单生效修复，注入脚本来源限制为 `https://zcode.z.ai`
- 通知 ID 改为确定性 SHA256（跨进程稳定、可撤回）；提醒方式三选（系统音 / 静音 / 强提醒）
- 设备索引损坏自愈重建；更新提示落盘时序修复（避免提示被永久吞掉）
- 应用内更新仅 Android 参与；发布包为 arm64 单包
