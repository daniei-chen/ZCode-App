# v1.6.0 — 首页工作台 + 一键体检 + 通知分组

> 版本：`1.6.0+40`。首页从"设备在不在线"升级成指挥台；"没通知"压成一次点击。

## 1. 首页工作台化（核心）

设备卡副标题现在是**这台电脑正在干什么**：

* **等待你的审批 · 任务名**（醒目警示色——哪里需要我点哪里）
* 运行中 / 已完成 / 出错 · 最近活跃任务名

数据由监控引擎每轮快照（15s）经跨隔离体共享存储写入（sid 为键，账号设备
与手动设备同身份），UI 每 5s 镜像刷新。审批待办优先于一切任务状态。

## 2. 一键体检（诊断页顶部）

「开始检查」一次点击跑完五环：**系统通知权限 → 电池白名单（软项）→
登录令牌（目录接口权威判定）→ 监控引擎 → 命令通道（软项）**，逐项
✅/⚠/❌，失败项带修复按钮（去开启/去登录/去设置），硬项全过即
"通知链路正常"。以后"没通知"不用导诊断包——自己一键定位。

## 3. 通知按设备分组

每条告警通知挂设备分组键（groupKey）+ 组摘要通知：多设备一晚上的通知
在通知栏折叠成**每设备一条**，展开看明细，不再刷屏。

## 4. 命令通道状态入体检

通知栏"允许/拒绝/回复"按钮的命令通道就绪态现在可在体检里看到——
为真机验证 v1.4 动作按钮提供观察点（试按钮后看体检"命令通道"是否 ✅）。

## 其他

* 新增 4 个摘要纯函数测试；全量测试通过（环境基线失败不变）；
* 通知/监控/登录链路（v1.3–v1.5）不受影响。
