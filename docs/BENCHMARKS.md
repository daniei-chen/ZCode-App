# 基准测试协议（v1.0.8 起）

真实设备上的量化验收协议。代码侧提供观测手段（诊断页 + 运行日志），
数据记录由持机人完成；结论写入本文对应小节。

> 原则：正式验收用 **Release 页面 CI 构建的 APK**，不用本地构建产物。

## 数据采集入口

- 设置 → 诊断信息：版本 / Android API / WebView Chromium 版本 / 设备与连接
  状态 / 观测计数（fetch 克隆命中、WS 帧、分片异常、队列丢弃）。
- 内存：`adb shell dumpsys meminfo com.zcode.app | grep -E "TOTAL|TOTAL PSS"`。
- 冷启动：`adb shell am start -W -n com.zcode.app/.MainActivity`（TotalTime）。

5 台额外观察：低内存设备下 renderer 是否被回收、切回时是否白屏、WS 是否
断连（诊断页连接状态 = 异常即为一次记录）、通知是否漏发（对照桌面端事件）。

## 2. 网络可靠性矩阵

每条记录：现象 + 诊断页更新状态 + 日志末行（`AppLog` 只含 path，不含凭证）。

| 场景 | 期望 | 实测 |
| -- | -- | -- |
| 正常 Wi-Fi | 直接下载 | |
| 移动网络 | 直接下载 | |
| VPN（共享出口，可能被 GitHub API 限流） | 走页面回退 + sidecar 摘要，仍可自动下载 | |
| 无网络 / DNS 超时 | 明确错误文案，可重试 | |
| API 403 但页面可达 | sidecar 恢复自动下载 | |
| sidecar 404 | 引导 GitHub 页（fail-closed） | |
| 下载中断（切飞行模式再恢复） | `.part` 保留，重试断点续传 | |
| 下载取消 | 断点清理，回到可重下状态 | |
| Wi-Fi ↔ 5G 切换 | 会话不掉线或自愈 | |
| 系统休眠 / 后台 30min 后回前台 | WebView 存活或可恢复 | |

## 4. 记录要求

- 每个场景至少 1 台主流机（Android 13/14）+ 1 台旧机（Android 10/11）+ 1 台平板。
- 测试期间诊断页截图随记录保存（截图前确认无会话内容）。
