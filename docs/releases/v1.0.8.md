## ZCode App v1.0.8

**WebView Hardening & Architecture Cleanup** —— 三版内容一次性收口。

### W1 页面级信任模型

- `isTrustedOrigin`（官方站点）与 `isTrustedRemotePage`（官方远控页面
  `/remote/v<数字>`）分层；主框架导航只放行远控页面，显式非 443 端口一律拒绝
- 导入校验与设备信任同步收紧到页面级
- 五个高权限 JS bridge 回调在 Dart 侧统一二次校验当前主文档（`_bridgeAllowed`）

### W3 第三方 Cookie 最小化

- `thirdPartyCookiesEnabled: false`（真机全流程 smoke 通过后保持）

### K1/K2 KeepAlive 历史清理

- `KeepAliveService.kt` 与 `services/keepalive.dart` 删除，通道更名 `zremote/battery`
- 设置页文案改为"改善后台运行稳定性"，不承诺后台保活

### Reliability

- EventObserver 遥测：fetch 克隆命中/跳过、WS/SSE 消息、分片异常、队列丢弃
  计数（只含数字），诊断页可见
- fetch 白名单：只 clone 事件相关命名空间，未命中可核对
- 分片装配：`fragmentIndex` 范围与 `fragmentCount` 上限校验、60 秒过期清扫
- CI 分层：fast check 必跑；Android 构建与模拟器 E2E 按路径过滤触发；
  PR 增加依赖评审

### Production Engineering

- **AppLog** 统一日志（环形 500 条，Release 只保留白名单事件）
- **诊断中心**（设置 → 诊断信息）：版本 / Android 与 WebView 版本 / 设备与连接
  状态 / 通知权限 / 电池优化 / 生物识别与最近任务遮罩 / 更新状态 / 观测计数 /
  运行日志，用户主动复制导出；绝不显示 sid/hash/token/会话内容
- **Dependabot**（pub + github-actions，weekly）
- **APK 产物来源证明**（`gh attestation verify` 可验证由本仓库 Actions 构建）
