## ZCode App v1.1.0

一次以外部深度审计为输入的加固版本：从"能用"过渡到"可证明"——发布链、供应链、
设备生命周期、通知链路、日志与诊断、无障碍与支持范围都补上了可复核的证据。

> 本版默认以 **Pre-release** 发布：应用内更新器只认 `/releases/latest`，因此
> 不会向普通用户推送；真机矩阵与长稳观察完成后由维护者手动转为正式版。

### 可靠性

- **设备生命周期按 deviceId 统一**（换凭证 = 换身份）：删除/更换链接不再让当前
  会话漂移到别的设备；旧凭证下的 warmup 记录与遥测一并失效
- **DeviceStore 崩溃一致性**：读失败显式上报（不再静默当空）；写操作串行化，
  并发添加/改名/排序后索引本身保持完整；索引损坏自愈补上"缺失/不完整"场景
- **黑屏与首载失败出口**：20s 无 loadStop 或页面持续空白先静默重载一次，
  预算用尽进入可重试错误卡；文档加载完成不再被当成"在线"（只有 relay 证据才算）
- **Renderer 回收/无响应**：以新 generation 重建 WebView，并同步设备状态为异常

### 通知与交互

- **跨消息幂等**：同一 (类型, 任务, 摘要) 在 2 分钟窗口内只提醒一次；任务新一轮
  照常提醒；`resolved` 清理只针对该任务
- **待处理交互按任务维护**：解决一个请求不再误清另一个
- **跳转确认**：点通知跳转现在会回报结果（`found`/`timeout`/`superseded`），
  失败给出可解释提示，不再静默停在任务列表

### 观测与诊断

- **结构化日志**：每条日志带事件码与白名单字段（route 只留 `scheme://host/path`、
  设备只记 8 位短 id、异常摘要脱敏截断），写入前统一再过一次脱敏
- **遥测按设备分开**：两台设备交错上报不再互相覆盖；只接受白名单计数键与有限值
- **诊断包**：一键复制已脱敏的版本/平台/设置/设备短 id/计数/日志（canary 零命中
  回归）；诊断页新增 WebView 本地存储清单与清理触发点

### 安全

- **生物识别门禁入口**：设置页可开启/关闭，两个方向都要先通过系统验证；
  生物识别不可用时拒绝开启（关闭允许退回系统锁屏凭据）
- **主 frame 桥令牌**：所有 bridge 消息必须带每代随机令牌（跨域子 frame 无法伪造）；
  消息 schema/尺寸门禁统一 fail-closed
- **凭证指纹去重**：只带 token（无 sid）的链接也能正确去重，比较的是 SHA-256 摘要
- **扫码失败可恢复**：相机被占用/不支持不再黑屏，给出可读原因 + 重试 + 改用粘贴

### 无障碍与自适应

- 字体 100%/130%/200% × 最窄 320dp / 常规 411dp / 平板 800dp / 横屏 1280×800
  全矩阵无溢出（自动化回归）；纯图标按钮补齐可朗读标签；信息类弹窗可滚动

### 发布与供应链

- **来源门禁**：只有受保护 main 上的提交能出签名包；tag 必须与 `pubspec.yaml` 一致；
  versionCode 必须递增；签名证书必须与上一稳定版一致
- **四重 digest 一致**：重算 APK SHA-256 = sidecar = manifest = attestation subject；
  附 GitHub 构建来源证明（`gh attestation verify`）
- **三层 SBOM**：Dart 依赖（含依赖图）+ Android release 运行时（含 POM 许可与
  真实解析边）+ APK 原生库（逐个 SHA-256），并把本次 APK 摘要写进 SBOM 根组件
- **依赖漏洞门禁**：发布前用 OSV 扫描随包发布组件，high 及以上未豁免即拒绝发布；
  例外必须带原因与到期日，过期即失败
- **注入脚本校验器**：观测钩子、跳转脚本、页内返回脚本的 JS 语法与边界行为断言
  （含"点了控件但页面没变"不得谎报成功）

### 本版回归修复（用户上报）

- 修复 **手机端对话页按返回不回对话列表**：页内返回改为多策略匹配（含纯图标返回键
  的左上角几何启发式）+ 点击后内容签名自证 + 结果回执；平板不再被短路
- 补齐 **返回层级**：设置/诊断等推入页面先弹栈回到上一个页面 →
  对话页回对话列表 → 对话列表露出设备页 → 设备页退出应用（手机与平板同一套规则）

### 已知边界

- 支持范围与限制见 [docs/SUPPORT.md](../SUPPORT.md)（Android 7.0+、仅 arm64-v8a、
  不支持 iOS；CI 实测 API 30/34）
- 真机矩阵（厂商 ROM、1/2/3/5 设备并发、网络/后台矩阵、48h 长稳）由维护者发布前手工执行
