## ZCode App v1.0.8

**WebView Hardening & Architecture Cleanup**：只做三件核心事（W1 + W3 + K1/K2）。

### 变更

- **W1 页面级信任模型**：`isTrustedOrigin`（官方站点）与 `isTrustedRemotePage`（官方远控页面 `/remote/v<数字>`）分层；主框架导航只放行远控页面，显式非 443 端口一律拒绝；五个高权限 JS bridge 回调在 Dart 侧统一二次校验当前主文档仍是远控页面
- **W3 第三方 Cookie 最小化**：`thirdPartyCookiesEnabled: false`（此前无依赖证据；真机全流程 smoke 通过后保持，失败则记录依赖流程再评估）
- **K1 KeepAlive 历史架构彻底删除**：`KeepAliveService.kt` 与 `services/keepalive.dart` 移除，原生通道更名 `zremote/battery`，旧安装清理改用字符串组件名
- **K2 文案改真实**：设置页改为"改善后台运行稳定性"，不承诺后台保活
- 安全不变量门禁扩充：远程页判定、端口拒绝、bridge 守卫、Cookie 关闭、KeepAlive 文件缺失
