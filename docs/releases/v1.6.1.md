# v1.6.1 — 登录过期主动通知 + 两个擦除真 bug 修复 + 本地测试全绿

> 版本：`1.6.1+41`。链路收尾版：通知的每一次沉默都有解释。

## 1. 登录过期主动通知

JWT 失效后，监控/命令通道/设备目录会静默死亡——现在会发一条**一次性**
通知「ZCode 登录已过期」（常驻式，重新登录成功自动撤掉），点按直达
重新登录入口。这是通知链路最后一块"沉默故障"。

## 2. 两个真 bug（修测试时挖出，真机同样受益）

* **擦除流程可被饿死**：锁定擦除的"清除并关闭"会 await 安全存储/WebView
  清理——platform 通道异常时这些调用可能**挂起**（不止抛异常），导致
  门禁关不上、用户被锁在门外。修复：擦除改为后台尽力而为（三步彼此
  隔离 + 5s 超时预算），关门禁立即生效、不再依赖擦除结果。
* **门禁偏好持久化失败即卡死**：`set(false)` 先写盘再更新状态——存储
  异常时门禁同样关不上。修复：持久化失败只留痕日志，内存状态必须生效
  （下次冷启动读回旧值会重新锁定，安全方向不变）。

## 3. 本地测试基线全绿（历史首次）

根因是 Flutter SDK 一直住在**中文路径**（shader 编译器处理不了，
5 个"环境性失败"由此而来）——SDK 已物理迁移到 `D:\flutter-sdk`
（无中文），5 个失败全部转绿，其中 2 个顺带挖出上面的真 bug。
全量 591 个测试零失败。

`scripts/build_release.sh <version>`：前置检查（tag 唯一性/doc-drift/
analyze/test）→ 构建 → 验签（证书指纹锁定）→ sha256 侧车 → 发布，
五步一键化，任一步失败即停。
