# v1.5.0 — 账号为中心：登录即见设备 + 黑白原生设计

> 版本：`1.5.0+38`。方向升级：从"扫码导入设备"变成 ZCode 原生的
> "登录账号 → 自动发现设备"模型，整套 UI 换成黑白单色体系。

## 1. 账号为中心的设备管理（核心）

* **开局添加账号**：首页新增「登录账号，自动发现设备」——内嵌官方
  登录流（OAuth 全程官方页面，App 只捕获登录令牌），登录完成自动
  返回原生首页；
* **设备自动出现**：登录后调用官方设备目录接口
  （`GET /api/v1/remote/device`，与官方"选择电脑"页同源，端点与响应
  形状逆向自页面代码的校验模块）自动列出账号下所有开启远程控制的
  电脑——**不再需要扫码或粘贴链接**；
* **实时同步与探活**：目录每 30 秒轮询；电脑端新增/移除设备、上下线
  （绿点/灰点）首页即时反映；
* **首页直连**：点设备即连（URL 与扫码完全同构，登录态已在位，打开
  即配对）——不用进官方页面再选一次电脑；
* **登录过期可见**：令牌失效时首页出横幅提示重新登录，不再静默失联；
* 扫码/粘贴保留为手动添加方式（账号设备与手动设备同 sid 去重）。

## 2. 黑白原生设计

对齐 ZCode 官方视觉：全局 accent 从蓝色改为**黑（浅色模式）/白
（深色模式）**单色体系，背景与描边对齐官方选择页的暖灰值；设备
图标改为无色大图标 + 左下角**探活状态点（绿=在线，灰=离线）**——
绿色是界面里唯一的彩色，一眼看出"进得去还是进不去"。

## 升级提示

老用户升级后：若之前登录过远控页，令牌已就位，首页会直接出现
「账号设备」区；没有则点「登录账号」一次即可。

## 其他

* 测试 582 过（新增设备目录解析 3 个），5 个环境性失败与 main 基线一致；
* 诊断/监控/通知链路（v1.3.x/v1.4.x）不受影响。
