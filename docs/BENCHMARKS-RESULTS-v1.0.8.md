### 明确未覆盖（必须真机）

- 真实 VPN/运营商出口的 GitHub API 限流、真实 4G/5G ↔ Wi-Fi 切换
- 厂商 ROM（MIUI/HyperOS/One UI）省电与后台策略、灭屏 30min、低内存杀进程
- 真实多桌面 1/2/3/5 台（同链接多设备会触发桌面端 session 冲突，不代表真实场景）
- 通知由桌面端事件（审批/完成/失败）触发的真实链路（本次仅验证测试通知）
- 断点续传/下载取消（需要新版本发布才能真正走下载链路）
- 24–48h soak（本次为 15 分钟后台趋势采样）
