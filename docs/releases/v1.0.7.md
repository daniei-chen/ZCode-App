## ZCode App v1.0.7

Release & Security Closure：发布链与更新器收口。本版本起仅支持 Android。

### 变更

- 更新器 fail-closed：资产必须携带合法 SHA256 digest 才自动下载；资产命名只认 `ZCode-v<版本>.apk` 精确名，不再回退任意 `.apk`
- 安装前预校验升级：包名 + versionCode + 签名证书 SHA256 全部比对，"无法降级安装(-25)"、包名不符、签名不符都在应用内以人话拦截
- Android 8+ 未授予"安装未知应用"时先引导系统授权页，授权返回后再安装，不再让系统安装器直接报错
- 更新下载支持取消，取消后清理断点文件
- 新增最近任务隐私遮罩：开启生物识别后切后台瞬间遮蔽应用快照（FLAG_SECURE），回前台立即恢复，前台截图不受影响
- DeviceStore 索引自愈重写：排除索引键自身、拒绝解析失败与键值 id 不符的坏数据
- 完全移除 iOS：不再发布 IPA，项目定位 Android-only
- 发布全自动：tag 推送后 CI 完成 tag↔pubspec 校验 → 签名构建 → arm64 ABI 验证 → SHA256 → GitHub Release，全程无手工上传
