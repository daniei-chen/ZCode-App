## 模拟器预验证（2026-09-12，非设备证据，不计入验收）

环境：Android 15（API 35）x86_64 模拟器 + 官方 `ZCode-v1.0.8.apk`（arm64 经系统转译安装）。

已验证（仅代表 Web 层）：

- 应用内更新检查："当前已经是最新版本 v1.0.8"（GitHub API 路径通畅）
- 真实控制链接导入 → 自动进入 WebView → 远控页连接建立（"已连接到当前桌面窗口"）
- 工作区/任务数据完整加载（7 工作区 · 12 任务）
- 会话正文完整加载（用户消息 + 助手回复）；SPA 路由（列表 → 会话）无拦截
- W1 页面级信任无误拦：全流程无 `nav blocked` 记录
- W3 第三方 Cookie 关闭：上述全部功能正常
- 后台 → 回前台：同一会话页原样恢复（WebView 常驻生效）
- logcat 无 FATAL/崩溃

未覆盖（按设备/网络/后台矩阵在真机完成）：通知与通知权限、VPN/限流/弱网/断点续传、
厂商 ROM 后台策略/省电/进程回收、1/2/3/5 台压测、长时间 soak。
