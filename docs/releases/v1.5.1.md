# v1.5.1 — 空态账号优先修正

> 版本：`1.5.1+39`。用户反馈：没登录时空态仍是旧的"接入设备"（扫码/粘贴）
> 占主位——登录应该是唯一主角。

## 变更

* **未登录**：整个空态就是"登录账号，自动发现设备"大卡（Z 徽章语言 +
  黑色主按钮）；扫码/粘贴收进卡底一行小字（手动兜底，不再是主角）；
* **已登录、账号暂无设备**：新引导卡——"在电脑端 ZCode 用同一账号登录
  并开启远程控制，设备会自动出现在这里" + 刷新按钮 + 手动兜底；
* 旧"接入设备"空态仅保留给存储异常兜底路径。

> 账号一加，目录里的所有设备自动扫出并 30 秒一轮实时同步（v1.5.0 能力，
> 本次只是把入口的主从关系摆正）。
