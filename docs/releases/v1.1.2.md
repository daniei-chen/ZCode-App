## ZCode App v1.1.2

> 与 v1.1.1 内容相同（审计加固全集 + 出站 URL 策略 + 返回修复），差别只有一处
> **发布链自身的修复**：`v1.1.1` 的 tag 冻结在修复前的提交上，而 tag 规则集禁止
> 移动/删除 tag（审计验收项），因此按规则以补丁版本重新发布。默认仍是
> **Pre-release**（应用内更新器只认 `/releases/latest`）。

### 本版修复

- **发布工作流：Gradle 依赖清单步骤用 `bash` 调用 wrapper**。上一版在 Ubuntu 上用
  `sh ./gradlew`（`/bin/sh` = dash），dash 无法解析 Gradle wrapper 的 bash 语法，
  报 `./gradlew: 154: Syntax error: "(" unexpected`，导致三层 SBOM 的 Maven 层无法
  生成、发布被 gate 拦下（这是保真的失败：SBOM 覆盖不全就不发布）。

### 内容清单（与 v1.1.1 相同）

- v1.1.0 计划的全部加固：可靠性 / 通知与交互 / 观测与诊断 / 安全 / 无障碍 /
  发布与供应链（详见 [v1.1.0.md](v1.1.0.md)）；
- 出站请求 URL 策略（https + host 白名单 + 拒绝 localhost/环回/私有/保留地址 +
  重定向逐跳校验）；
- 用户可见修复：对话页返回回到对话列表、返回层级（设置页先弹栈 → 对话页 → 对话列表
  → 设备页），手机与平板同一套规则。

### 已知边界

- 支持范围与限制见 [docs/SUPPORT.md](../SUPPORT.md)（Android 7.0+、仅 arm64-v8a、
  不支持 iOS；CI 实测 API 30/34）。
- 历史 tag `v1.1.0`、`v1.1.1` 均未发布（被后续补丁版本取代）；如需清理需调整
  tag 规则集。
