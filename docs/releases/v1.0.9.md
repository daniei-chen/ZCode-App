## ZCode App v1.0.9

WebView 观测收敛 + 供应链产物 + 治理文档。

### 变更

- **WS/SSE 白名单**：只观察官方 relay（实测端点 `wss://zcode.z.ai/ws`）；其他
  WebSocket/SSE 完全透明——不挂监听、不读正文、不上报，只计数（诊断页可见
  `wsIgnored`/`sseIgnored`）
- **Renderer 崩溃恢复**：渲染进程被系统回收后进入错误卡，重试以新 generation
  重建整个 WebView；`onRenderProcessUnresponsive` 提供 release 可见的卡死信号
- **Bridge 消息 schema/尺寸门禁**：六个 bridge 回调统一类型与长度校验（theme/
  viewState/seen/event/ws/stats），超限或类型不符丢弃并计数
- **日志修复**：导航被拦与黑屏守卫静默重载升级为 release 可见（只含 path，
  凭证永不落日志）
- **DeviceStore 索引去重**（混沌测试暴露的真实缺陷）

### 发布链（首次完整启用）

- 新增 **CycloneDX SBOM**（119 个依赖组件）与 **release-manifest.json**
  （version/versionCode/commit/ABI/APK SHA256/签名指纹/工具链版本）
- **Attestation 生成后立即自验证**：来源证明不可验证的发布直接失败
- CI emulator 覆盖 **API 30/34 矩阵**

### 文档与测试

- 新增：威胁模型（T1-T12 资产-威胁-防御-证据矩阵）、SECURITY（私有漏洞报告
  已开启）、隐私数据流、运维手册（密钥灾备与回滚制度）
- 新增 chaos/模糊测试电池（解析器、更新器、DeviceStore、sidecar 摘要），
  全套 367 项测试通过
